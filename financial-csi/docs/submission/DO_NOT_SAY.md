# DO NOT SAY

Explicitly prohibit these claims unless actual evidence directly proves them during the Q&A. Use the precise alternatives on the right.

| **DO NOT SAY THIS** | **SAY THIS INSTEAD** |
| :--- | :--- |
| "We detect all fraud." | "We mine for unspecified interaction patterns associated with merchant loss." |
| "Our AI prevents fraud." | "Our AI translates mathematical discoveries into forensic explanations." |
| "Our AI guarantees savings." | "Our Monte Carlo simulations estimate potentially preventable loss." |
| "Our model is 100% accurate." | "This pattern maintains a high risk multiplier on the held-out test data." |
| "These patterns cause fraud." | "These patterns have a statistically validated association with financial loss." |
| "These are completely unknown patterns."| "These are emergent patterns not explicitly encoded in the baseline rules." |
| "Razorpay is using our system." | "We natively ingest Razorpay Test Mode webhooks." |

| "The simulation proves savings." | "The simulation bounds potential savings under specific efficacy assumptions." |
| "The LLM detected the fraud." | "The Apriori engine discovered the pattern; the LLM explained it." |
